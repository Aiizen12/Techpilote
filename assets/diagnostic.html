Aide au diagnostic N1

Cochez des symptômes pour les pannes matérielles, ou utilisez les arbres de décision dédiés pour Citrix et les incidents navigateur / application web.

Les 5 bonnes pratiques

    Les deux gestes systématiques

      Filtrer par sujets

      Un seul sujet est affiché à la fois : matériel, Citrix, ou navigateur / application web.

      Panne matériels
      Mode matériel activé : recherchez un symptôme, cochez-le, puis copiez la synthèse du ticket.

      Filtrer par matériel

      Par défaut, tous les matériels sont affichés. Cochez un ou plusieurs matériels pour limiter l’affichage.

      Arbre de décision Citrix

      Répondez aux questions et indiquez les tests réalisés pour obtenir les actions N1, l’interprétation, la résolution possible ou l’escalade N2.
      Progression Citrix 0 / 15 réponses

      1. Qualifier

      2. Vérifier

      3. Actions N1

      4. Isolement du problème

      Renseignez les réponses ci-dessus pour obtenir l’analyse Citrix.

      Arbre de décision — Bureau virtuel Citrix ne se lance pas

      Répondez aux questions pour qualifier l'incident, identifier si le problème est local, lié aux droits ou à la plateforme.
      Progression 0 / 10 réponses

      1. Accès au portail

      2. Comportement au clic

      3. Périmètre de l'incident

      4. Actions réalisées

      Renseignez les réponses ci-dessus pour obtenir l'analyse.

      Arbre de décision Navigateur / application web

      Répondez aux questions pour qualifier l’incident, guider les tests et déterminer la résolution ou l’escalade.
      Progression navigateur 0 / 20 réponses

      1. Qualifier l’incident

      2. Premier test et environnement

      3. Reproduire et rafraîchir

      4. Comparatifs navigateur / profil

      Renseignez les réponses ci-dessus pour obtenir l’analyse navigateur / application web.

      Symptômes à cocher

      Vous pouvez combiner recherche, filtre par sujet, filtre par matériel et sélection manuelle.

      Le texte saisi coche automatiquement les symptômes correspondants sur les pannes visibles.
      Aucune recherche active.
      Tant que ce menu n’est pas utilisé, tous les types de panne restent visibles.

      Résultats du diagnostic

      Aucun symptôme sélectionné.
      Sélectionnez des symptômes à gauche pour les pannes matérielles.

      Petits matériels

      Les petits matériels en panne sont achetables par les utilisateurs. Ils font une note de frais pour se faire rembourser.

      • Souris filaires ou sans-fil simples
      • Claviers filaires ou sans-fil simples
      • Tapis de souris
      • Repose-poignets
      • Câbles HDMI, DisplayPort, USB, Ethernet RJ45
      • Adaptateurs USB-C vers HDMI, USB-A vers USB-C
      • Chargeurs de téléphone
